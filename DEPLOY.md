# Deploying the demo to Streamlit Community Cloud (cached mode)

Push this repository to GitHub, create a new app on share.streamlit.io pointing at `demo/app.py`, and set **Advanced settings → Python 3.12** and **requirements file → `requirements-demo.txt`** (it holds only `streamlit`, `pandas`, `tiktoken`, `python-dotenv`; no torch/transformers/spaCy, so the app builds in about a minute and starts in a few seconds). No secrets are required: the app detects that it is not running on a machine with the local models and starts in **cached** mode, which reads the pre-recorded scenario runs in `demo/cached/<model>/` and the measured tables in `results/summary.csv` — both committed. The "Try your own" tab and the live toggle are shown but disabled in that mode (they need the local ML models and an API key; run `streamlit run demo/app.py` locally with the full `requirements.txt` and a filled `.env` for those). If you ever want live mode on your own server, copy `.streamlit/secrets.toml.example` to the app's Secrets and set `CONTEXTSHIELD_DEMO_MODE = "live"` plus the `LLM_*` keys.
